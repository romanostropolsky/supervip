# Диспетчерська система обліку замовлень поїздок

Веб-панель для диспетчера (замовлення, водії, звіти) + Telegram-бот для водіїв
(сповіщення, підтвердження, етапи поїздки, локація).

## Технології
- Backend: Node.js + Express
- База даних: PostgreSQL
- Сповіщення водіям: Telegram-бот (Telegraf)
- Frontend: одна HTML-сторінка, без збірки (fetch до API)

## Модель даних (важливо, якщо продовжуєш редагувати)
- **Замовлення**: клієнт (вільний текст), кількість пасажирів, час подачі, довільний
  список точок маршруту (2–8, кожна — місто + необов'язковий час), ціна і комісія
  вводяться диспетчером вручну.
- **Водій**: ім'я, телефон, модель авто, клас (вільний текст із фіксованого списку
  на формі), кількість місць, власна ставка (`tariff_rate`, довідково).
- Фіксованих маршрутів і тарифної сітки більше немає — це свідома зміна порівняно
  з першою версією системи.

## Крок 1. Створити Telegram-бота
1. У Telegram відкрити **@BotFather**
2. `/newbot`, вказати назву і юзернейм
3. Скопіювати токен — це `TELEGRAM_BOT_TOKEN`

## Крок 2. Розмістити на хмарі (Render або Railway)
1. Залити код у репозиторій на GitHub — **заміни ВСІ файли, не тільки окремі**
2. Render: **New → Web Service** з цього репозиторію
3. **New → PostgreSQL**, скопіювати `Internal Database URL`
4. Environment: `DATABASE_URL`, `TELEGRAM_BOT_TOKEN`, `JWT_SECRET` (довгий випадковий рядок)
5. Build: `npm install`, Start: `npm start`

## Крок 3. Створити акаунт адміністратора
Один раз через Shell на Render:
```
npm run create-dispatcher -- логін пароль admin
```
Адмін бачить вкладку «Диспетчери» й керує акаунтами прямо з панелі.

## Крок 4. Локальний запуск
```
cp .env.example .env
npm install
npm run create-dispatcher -- admin admin123 admin
npm start
```

## Функції
- Ролі диспетчерів (admin/dispatcher), керування акаунтами з панелі
- Нове замовлення: клієнт, пасажири, час подачі, довільні зупинки, ціна/комісія вручну
- Редагування замовлення, поки воно в статусі «Нове»
- Призначення водія → сповіщення в Telegram із кнопками підтвердити/відхилити
- Проходження етапів поїздки водієм у боті (довільна кількість зупинок)
- Локація водія: вибір міста зі списку або GPS-кнопка в боті; список міст керується
  диспетчером у вкладці «Міста»
- **Ручне вмикання/вимикання водія диспетчером** (вкладка «Водії»)
- Захист від задвоєння замовлень і водіїв при швидкому повторному натисканні кнопки
- Звіт з експортом у справжній Excel (.xlsx)

## Свідомо не реалізовано
- SMS-сповіщення — лише Telegram
- Автоматичний розрахунок відстані/вартості між довільними зупинками (ціна вводиться вручну)

## ⚠️ Якщо цей репозиторій редагує ще хтось/щось інше
Кілька разів `server.js` і `index.html` перезаписувались зовсім іншим кодом, що ламало
авторизацію, ролі й бота. Якщо над репозиторієм паралельно працює інший інструмент —
координуйте зміни або тимчасово зупиніть автогенерацію, інакше роботу буде втрачено знову.
