# Диспетчерська система обліку замовлень поїздок

Веб-панель для диспетчера (облік замовлень, водії, маршрути, тарифи, звіти) +
Telegram-бот для водіїв (сповіщення, підтвердження, етапи поїздки).

## Технології
- Backend: Node.js + Express
- База даних: PostgreSQL
- Сповіщення водіям: Telegram-бот (бібліотека Telegraf)
- Frontend: одна HTML-сторінка (без збірки, простий `fetch` до API)

## Крок 1. Створити Telegram-бота
1. У Telegram відкрити **@BotFather**
2. Надіслати `/newbot`, вказати назву і юзернейм (наприклад `my_taxi_dispatch_bot`)
3. Скопіювати виданий токен — це `TELEGRAM_BOT_TOKEN`

## Крок 2. Розмістити на хмарному хостингу (Render або Railway)

### Варіант A — Render.com
1. Залити цей код у репозиторій на GitHub
2. На Render: **New → Web Service**, підключити репозиторій
3. **New → PostgreSQL** — створити базу, скопіювати `Internal Database URL`
4. У Web Service → Environment додати змінні:
   - `DATABASE_URL` = рядок з кроку 3
   - `TELEGRAM_BOT_TOKEN` = токен бота
   - `JWT_SECRET` = будь-який довгий випадковий рядок
5. Build Command: `npm install`
6. Start Command: `npm start`
7. Задеплоїти

### Варіант B — Railway.app
1. Залити код у GitHub-репозиторій
2. **New Project → Deploy from GitHub repo**
3. **New → Database → PostgreSQL** у тому ж проєкті — Railway сам підставить `DATABASE_URL`
4. У Variables сервісу додати `TELEGRAM_BOT_TOKEN` і `JWT_SECRET`
5. Railway задеплоїть автоматично при пуші в репозиторій

## Крок 3. Створити перший акаунт (адміністратора)
Після першого деплою один раз виконати (Render: вкладка Shell; Railway: `railway run`):
```
npm run create-dispatcher -- ваш_логін ваш_пароль admin
```
Роль `admin` дає доступ до вкладки **Диспетчери**, де можна створювати інші акаунти
(звичайних диспетчерів — роль `dispatcher`, або ще адміністраторів) прямо з веб-панелі,
без повторного заходу на сервер.

## Крок 4. Локальний запуск (для перевірки перед деплоєм)
```
cp .env.example .env
# заповнити DATABASE_URL (локальний Postgres), TELEGRAM_BOT_TOKEN, JWT_SECRET
npm install
npm run create-dispatcher -- admin admin123
npm start
```
Відкрити http://localhost:3000 — увійти як `admin` / `admin123`.

## Як користуватись
1. **Маршрути і тарифи** — додати до 10 маршрутів (з опційними 1–2 зупинками) і до 5 класів авто, заповнити ціну й комісію для кожної пари.
2. **Реєстрація водія** — вказати ім'я, телефон, клас авто. Система видасть код прив'язки виду `/start abc123`.
3. Водій відкриває бота в Telegram і надсилає цей код — акаунт прив'язується автоматично.
4. Водій кнопками "🟢 Вийти онлайн" / "🔴 Піти офлайн" керує своєю доступністю.
5. **Нове замовлення** — диспетчер обирає маршрут, клас авто, кількість пасажирів, багаж; за наявності вільного водія може одразу призначити його — водій миттєво отримає повідомлення в Telegram з кнопками "Підтвердити" / "Відхилити".
6. Після підтвердження водій кнопками в боті проходить етапи поїздки (забрав пасажира → зупинки → прибув) — дані одразу видно диспетчеру у вкладках **Замовлення** і **Водії**.
7. **Звіт** — оборот, комісія, розбивка по водіях і маршрутах.

## Що вже реалізовано
- Кілька акаунтів диспетчерів з ролями: **admin** керує акаунтами (вкладка «Диспетчери»), **dispatcher** — звичайний доступ до роботи із замовленнями.
- Редагування замовлення, поки воно в статусі «Нове» (маршрут, клас, пасажири, багаж; ціна й комісія перераховуються автоматично). Після призначення водію редагування закривається — можна лише скасувати.
- Експорт повного звіту в Excel (.xlsx) кнопкою «Завантажити Excel» на вкладці «Звіт»: зведення, розбивка по водіях, по маршрутах і повний список замовлень.

## Свідомо не реалізовано
- SMS-сповіщення — за вашим запитом, сповіщення лише через Telegram-бот.
